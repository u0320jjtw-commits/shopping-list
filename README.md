# 月間タスク管理

大カテゴリ・小カテゴリごとに、月の日付を横に並べて実施状況を記録するWebアプリです。

- 「さんすう」「こくご」「そのた」から小カテゴリを追加・削除できます。小カテゴリのタスク種別は決まっており、「ぶんしょう」「どっかい」は回数、それ以外は実施済み／未実施で記録します。
- 月を切り替えて過去・未来の実施状況を確認できます。タスク別・日別の小計と、月のお小遣い（記録した○または回数×10円）を表示します。
- 土曜日は薄い青、日曜日は薄い赤で表示します。
- タスクと日ごとの記録はブラウザー内に保存されます。
- 以前のToDoリストに保存されたタスクがある場合、初回起動時にタスク名を引き継ぎます。

`index.html` を静的ホスティング環境で配信して利用できます。
