# 月間タスク管理

大カテゴリ・小カテゴリごとに、月の日付を横に並べて実施状況を記録するWebアプリです。明るくポップなデザインで、タスク表をスクロールせずに見渡せます。

- 初期状態では「さんすう」「こくご」「そのた」の9つのタスクが登録されています。「タスク追加」から大カテゴリ・小カテゴリを自由に入力し、実施チェックまたは回数記録を選べます。
- 月間表ではタスクごとの日別実施状況と小計を確認できます。月を切り替えて過去・未来の記録を確認できます。
- お小遣いは1実施につき10円で計算し、今月の見込み額と先月からの差額・比率を表示します。
- 「データ」では、選択中の月までの直近12か月の実施状況をタスクごとの積み上げ棒グラフで確認できます。大カテゴリごとに色分けし、各タスクの数値は棒の上にカーソルを合わせると確認できます。
- 土曜日は薄い青、日曜日は薄い赤で表示します。
- タスク・カテゴリと日ごとの記録はブラウザー内に保存されます。
- 以前のToDoリストに保存されたタスクがある場合、初回起動時にタスク名を引き継ぎます。

`index.html` を静的ホスティング環境で配信して利用できます。
